# AI Farming Assistant

## Project Description

AI Farming Assistant is a chatbot designed to help farmers with basic
farming-related information and guidance.

The chatbot provides options such as:

- Choose a Crop
- Fertilizer Guidance
- Identify Diseases
- Check Market Prices
- File Upload
- Conversation History
- Feedback

## Technologies Used

- HTML
- CSS
- Botpress
- Webchat
- AI Chatbot

## How to Run the Project

1. Open this project folder in Visual Studio Code.
2. Open `index.html`.
3. Install the Live Server extension in VS Code.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. The AI Farming Assistant chatbot will open in the browser.
7. Internet connection is required.

## Working

The frontend is created using HTML and CSS.
The AI chatbot is integrated using Botpress Webchat.
The chatbot's AI workflow is hosted and managed through Botpress.

## Integration

The Botpress Webchat is embedded into the webpage using an iframe.

## Conclusion

AI Farming Assistant provides an easy-to-use conversational interface
for farmers to get farming-related assistance.
